# Start Here

If you're new to ML, don't jump straight to Day 1 — spend a few days here first.
This challenge assumes you can already write Python and are roughly comfortable
with NumPy/pandas, and that you have *some* intuition for what gradient descent,
a training/test split, and overfitting mean. If any of that is new, these
resources get you there.

## Math you actually need (not more than this)
You don't need a math degree. You need: derivatives and the chain rule
(enough to follow "the gradient of the loss w.r.t. the weight"), basic linear
algebra (vectors, matrices, dot products), and basic probability (mean,
variance, conditional probability).

- **3Blue1Brown — Essence of Linear Algebra** (YouTube playlist): the best
  visual intuition for vectors/matrices you'll find anywhere.
  https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab
- **3Blue1Brown — Essence of Calculus** (YouTube playlist): same, for
  derivatives and the chain rule.
- **Khan Academy — Statistics & Probability**: solid, free, no signup required
  for browsing. https://www.khanacademy.org/math/statistics-probability

## Python for ML you actually need
If you can write a function and a for-loop, start here and you'll pick the
rest up as you go through the challenges:
- **NumPy quickstart** (official docs): https://numpy.org/doc/stable/user/quickstart.html
- **pandas 10 minutes to pandas** (official docs): https://pandas.pydata.org/docs/user_guide/10min.html

## The best single "what is ML" resource
- **3Blue1Brown — Neural Networks playlist**: even though it's about neural
  nets specifically, the first video is the best 20-minute intuition-builder
  for "what is a model actually doing" that exists.
  https://www.youtube.com/playlist?list=PLZZWrBYkx7Otcjr3eCLZDCgfpqnxMY29s

## A proper course, if you want structure
- **Machine Learning Specialization** (Andrew Ng, DeepLearning.AI/Stanford,
  free to audit on Coursera): the standard beginner course, still excellent.
  https://www.coursera.org/specializations/machine-learning-introduction

## The reference textbook (free, legal, official PDF)
- **An Introduction to Statistical Learning** (James, Witten, Hastie,
  Tibshirani) — the book most university intro-ML courses are built on.
  Free official PDF + R and Python labs.
  https://www.statlearning.com/

## How to use this folder day to day
Each other file in this folder maps to one of the 6 models. Before you start
that model's 4 prep days, skim the corresponding file — you don't need to
finish a whole course first, just get the shape of the topic in your head.
