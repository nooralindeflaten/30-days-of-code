# Model 1 — Supervised Learning: Reading Material

Covers: gradient descent, linear/logistic regression, classification metrics,
cross-validation, hyperparameter tuning.

## Core concepts
- **StatQuest — Linear Regression, Gradient Descent, Logistic Regression**
  (YouTube channel): short, clear, visual explanations of exactly these
  topics, no fluff. Search the channel for each topic name.
  https://www.youtube.com/@statquest
- **An Introduction to Statistical Learning**, Ch. 2–4 (linear regression,
  classification, resampling/cross-validation): https://www.statlearning.com/
- **scikit-learn User Guide — Model evaluation** (official docs): the
  reference for precision/recall/F1/ROC-AUC and when to use which.
  https://scikit-learn.org/stable/modules/model_evaluation.html

## Why cross-validation and metric choice matter
- **scikit-learn — Cross-validation** (official docs, has good diagrams):
  https://scikit-learn.org/stable/modules/cross_validation.html
- Google's **Machine Learning Crash Course — Classification** module covers
  precision/recall/imbalanced data clearly and briefly:
  https://developers.google.com/machine-learning/crash-course/classification

## If you want the deeper theory
- **An Introduction to Statistical Learning**, Ch. 5 (resampling methods) and
  Ch. 6 (regularization / ridge & lasso) — directly relevant to the bonus
  rounds in this model's challenges.
